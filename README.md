# 퀴즈 탐험대 함께하기

반 친구들과 같은 맵에서 동시에 푸는 퀴즈 게임입니다.

- **자유 탐험 함께하기**: 반 전체가 한 맵에 들어와 서로의 캐릭터를 보며 깃발 문제를 풀고, 실시간 순위가 나옵니다.
- **선생님 진행 퀴즈**: 선생님이 한 문제씩 띄우면 모두 광장의 O·X·번호 발판으로 달려갑니다.
- **선생님 관리자**: 반 만들기, 학생 아이디(반 코드 + 번호 + 비밀번호 4자리) 자동 생성, 로그인 카드 인쇄, 퀴즈 편집, 게임 진행, 학생별 기록 확인.

정적 파일 하나(`index.html`)로 되어 있고, 데이터는 Supabase에 저장됩니다.
